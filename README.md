#(`np-details`)

बाह्य API मा भर नपरी **Swiss Ephemeris (`pyswisseph`)** र **`nepali-datetime`** प्रयोग गरी विक्रम संवत् (B.S.) को पञ्चाङ्ग, ग्रह गोचर (Transit), र १२ वटै राशिको **दैनिक, साप्ताहिक, मासिक र वार्षिक राशिफल** जेनेरेट गर्ने Python प्रोजेक्ट।

## मुख्य विशेषताहरू

- **सटीक पञ्चाङ्ग र मुहूर्त (`panchang.py`):** काठमाडौँको निर्देशाङ्क र Lahiri Ayanamsa प्रयोग गरी तिथि, नक्षत्र, योग, करण, चन्द्र राशि, सूर्योदय/सूर्यास्त, चन्द्रोदय/चन्द्रास्त, राहुकाल, चौघडिया, अमृत काल, वर्ज्यम् तथा अन्य शुभ/अशुभ मुहूर्त गणना गर्छ।
- **ग्रह गोचर र Transit ट्र्याकिङ:** सूर्य, चन्द्र, मङ्गल, बुध, बृहस्पति, शुक्र, शनि, राहु र केतुको स्थिति निकालेर वर्षभरि कुन BS मितिमा कुन ग्रहले राशि परिवर्तन गर्‍यो (`transitEvents`) भन्ने पत्ता लगाउँछ।
- **दैनिक, साप्ताहिक, मासिक र वार्षिक राशिफल (`rashifal.py`):** `panchang_<year>.json` बाट बाह्य API बिना नै `daily`, `weekly`, `monthly`, `yearly`, वा `all` अवधिमा JSON र Markdown आउटपुट तयार गर्छ।
- **GitHub Actions स्वचालन:** `.github/workflows/generate-rashifal.yml` मार्फत हातैले (`workflow_dispatch`) वा तालिकाअनुसार (`schedule`) फाइल जेनेरेट गर्न सकिन्छ।
